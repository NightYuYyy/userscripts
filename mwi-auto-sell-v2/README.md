# [银河奶牛] 库存物品一键自动出售（极速版）v2

Milky Way Idle 一键出售的自写重构版。逐步轮询等待按钮出现，不用固定延迟，无 GM 权限依赖。

- 匹配：`https://www.milkywayidle.com/game*`
- 版本：2.0.0
- 作者：zhengjiyong（MIT）。原版见 `../mwi-auto-sell/`

## 用法

1. 进入游戏库存页，选中一个物品。
2. 按 `S`：前往市场 → 新出售挂牌 → 价格 +1 → 最多 → 发布 → 关闭。
3. 中英文按浏览器语言自动切换。英文按钮文本尚未实机验证。

## 配置（脚本顶部 `CONFIG`）

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `hotkey` | `s` | 触发快捷键 |
| `stepTimeout` | `3000` | 每步等待按钮出现的最长毫秒数 |
| `pollInterval` | `50` | 轮询间隔毫秒 |
| `priceClicks` | `1` | 点击价格「+」的次数，0 表示按最佳出售报价挂牌 |
