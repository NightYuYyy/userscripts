# [银河奶牛] 库存物品一键自动出售（极速版）

Milky Way Idle 库存物品一键出售助手，在原插件基础上优化出售速度。

- 匹配：`https://www.milkywayidle.com/game*`
- 版本：1.0.7.1
- 原作者：shenhuanjie（MIT），来源 [GreasyFork #536068](https://greasyfork.org/scripts/536068)

## 用法

1. 安装后进入游戏库存页，选中一个物品。
2. 按快捷键 `S` 或点击脚本按钮，一键前往市场并发布出售订单。
3. 中英文界面按浏览器语言自动切换。
